## 🚀 Featured Projects

### 🔧 Serviko: Technician Service Marketplace
Cross-platform mobile app connecting customers with nearby technicians (roadside assistance, appliance, furniture and construction repairs) with separate Customer, Technician and Company workflows.
- Weighted technician matching using proximity, ratings and experience
- Real-time chat, payments, ratings and dispute resolution
- AI receipt verification (Tesseract OCR + Gemini) and an AI phone-screen damage diagnosis service (FastAPI + TensorFlow + MobileNetV2)

**Tech:** React Native, Expo, TypeScript, Firebase, FastAPI, TensorFlow, Gemini API, Docker, GitHub Actions

### 🔍 ResQ-Portal: AI-Powered Lost & Found
MERN platform that helps students and staff recover lost items through smart matching and real-time chat.
- Matching algorithm using date, location, description and AI-generated image tags
- Gemini AI image tagging, Socket.IO anonymous chat, OTP-based secure handover

**Tech:** MongoDB, Express, React, Node.js, Socket.IO, Gemini API, Cloudinary, JWT

### 🏫 Campus Nexus: Smart Campus Operations Hub
Full-stack system for facility booking and maintenance ticketing, with a RESTful API.

**Tech:** Java, Spring Boot, React, MySQL, Maven

### 📈 NexaBiz HR: HR Management Dashboard
Lightweight dashboard giving an at-a-glance view of employee metrics, with charts.

**Tech:** React, Vite, Recharts, Node.js, Express, MongoDB Atlas
